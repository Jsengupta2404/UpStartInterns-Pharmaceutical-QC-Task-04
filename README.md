# UpStartInterns – Pharmaceutical Quality Control Internship | Task 04

## Pharmaceutical Quality Control & Stability Package

**Product:** Paracetamol Tablets IP 500 mg (Immediate-Release)

**Project date:** 17 November 2026

### Project Overview

This capstone project presents an educational pharmaceutical quality control and stability documentation package for Paracetamol Tablets IP 500 mg (Immediate-Release).

### Project Scope

- Raw-material quality control specifications for Paracetamol API
- Finished-product quality control specifications
- Proposed stability study protocol
- Long-term and accelerated stability conditions
- Stability data recording and trend analysis
- Batch-wise assessment of quality attributes
- OOS and OOT investigation considerations
- Application of ICH stability guidance

### Project Files

1. `Task04_Paracetamol_QC_Stability_Report.docx` – Detailed QC and stability report.
2. `Task04_Paracetamol_QC_Stability_Report.pdf` – PDF version of the report.
3. `Task04_Paracetamol_Stability_Data_and_Trends.xlsx` – Stability dataset, calculations, summaries and charts.

### Data Integrity and Limitations

This is an educational portfolio exercise. No physical samples were tested, and no manufacturer- or sponsor-supplied stability dataset was provided.

All numerical stability observations in the accompanying workbook are synthetic and were generated solely to demonstrate data recording, trending and interpretation.

The results must not be represented as experimental findings, validated release specifications, a regulatory stability commitment or evidence supporting an actual product shelf life.

Pharmacopoeial requirements must be verified against the current applicable Indian Pharmacopoeia and approved product specification before industrial use.

### Reference Framework

- Indian Pharmacopoeia – applicable Paracetamol and Paracetamol Tablets monographs.
- ICH Q1A(R2) – Stability Testing of New Drug Substances and Products.
- ICH Q1E – Evaluation of Stability Data.
